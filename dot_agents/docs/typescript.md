- **Runtime truth**: Validate untrusted input at boundaries; keep it `unknown` until parsed or narrowed.
- **Inference**: Infer locals, implementation details, and JSX returns. Annotate function parameters and top-level module returns. Check object constraints with `satisfies` without widening inferred types.
- **Narrowing**: Fix models or narrow through control flow, predicates, and assertion functions. Exclude `any`, non-null `!`, and unchecked `as` from application values; allow `as const`. If a TypeScript limitation requires an escape hatch, isolate it in one boundary or type utility and prove behavior with a test.
- **States**: Use discriminated unions with required fields, making impossible states unrepresentable; check exhaustiveness with `never`.
- **Source of truth**: Derive types from schemas, validators, contracts, or values for the same concern; decouple independently changing types. One definition per contract.
- **Generics**: Type parameters must preserve relationships between values. Prefer concrete types and readable unions over type-level cleverness.
- **Declarations**: Default to `type`; use `interface` for justified object inheritance, `extends`, or intentional declaration merging.
- **Strictness**: Preserve project strictness and compiler/lint safeguards; fix diagnostics at their cause.
