# Commit

## 1. Scope

Run `git status --short`; a clean tree ends the run. Existing staged changes
define the scope; when nothing is staged, run `git add -A`. Read `git diff --cached` in full and unstage anything unrelated or generated by accident, leaving its worktree contents intact. Stop and report any credential, private key, or other likely secret instead of committing it.

**Done when:** every staged hunk belongs to the requested change and contains no likely secret.

## 2. Format

Run the repository's formatter on the staged paths only, then re-stage those paths.

**Done when:** the staged files are formatted and the set of staged paths has not widened.

## 3. Commit

Repository commit rules override this fallback: Conventional Commits, subject at most 72 characters. A body is earned by one fact the diff cannot show (a decision taken, a constraint obeyed, a breaking impact), in at most two lines. Make one commit; split only when the user asks. Create each commit without another confirmation.

**Done when:** the staged hunks are committed.
